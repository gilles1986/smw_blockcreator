# Locale files and language menu

Status: open
Blocked by: 05
Spec: ../spec.md

All UI strings come from `locales/en.json`; the language menu lists every `locales/*.json` (built-in and user folder). Missing keys fall back to English. Short "Translating BlockCreator" doc.
